# Sales-Dashboards-Dashboard-Design-Tableau-
Sales Dashboards — Dashboard Design (Tableau)

Visual design and layout for two interactive sales dashboards in Tableau, focused on clear KPI presentation and readable data storytelling.

What this covers: Dashboard layout, chart selection, and visual design (KPI cards, category/regional breakdowns, trend lines, a state-level map) on a provided sales dataset. Data modeling and preparation were not part of this piece — the focus was the front-end design.

Dashboards:

Sales Dashboard — KPI summary cards (total cost, quantity sold, orders), orders by category, revenue by gender, orders by state (map), cost trend over time
Detailed Sales Dashboard — revenue by category, average order value by region, top-N profit by product, revenue vs. quantity trend

Tools: Tableau
